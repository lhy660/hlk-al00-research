# 2026-11-10 发布包目录整理清单

## 目标与决策

用户要求「产物文件跟源码分开放置，历史文件额外单独放置，各文档更新，
第一层自述文件详细写清目录职责」。确认后的方案：

1. **在 `hlk-root-dist/` 内分四层**：`bin/`（产物）、`src/`（源码）、
   `docs/`（文档）、`history/`（历史留档）。
2. **拆掉 `current/` 自包含快照**：产物并入 `bin/`、独有源码并入 `src/`，
   `current/MANIFEST.md5` 撤销，交付改为 `bin/ + src/ + 单一根 MANIFEST`。
3. 顶层 `README.md`（工作区）与包根 `README.md`（发布包）都重写目录职责章节。
